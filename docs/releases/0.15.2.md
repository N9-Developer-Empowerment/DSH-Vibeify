**Turn your AI work into a living magazine.**

This is the first versioned public GitHub Release of DSH Vibeify: an open-source, local magazine experience for DeepSeek Harness. ## Roll back or remove Vibeify

This is the first public GitHub Release, so the documented rollback is to ordinary DSH rather than to an earlier public release.

1. Finish any active DSH work and close the running DSH process.
2. Remove the installed Vibeify mode:

   ```bash
   dsh plugin --profile web remove --workspace-root dsh-vibeify
   dsh plugin --profile web remove --workspace-root dsh-vibeify-experience
   ```

3. Start DSH again with `dsh web`.

Removing Vibeify does not delete DSH sessions, Codex authentication, DeepSeek credentials, or browser-stored Vibe preferences. See the [full installation guide](../INSTALL.md) for profiles, updates, checks, and diagnosis.

## Honest boundaries

Vibeify is macOS-first and DSH is still a developer preview. It is not fully offline: the magazine shell and first edition are local, while AI work and public sources may use the connected providers and network. ChatGPT and DeepSeek are separate provider arrangements with separate limits and charges. Codex verification applies only when a Codex-led mode is installed. Vibeify is an independent community project, not an official DeepSeek or OpenAI product.
