# DSH Vibeify 0.15.3

**Your finished Vibes stay findable—and their music and video can travel with them.**

This release adds a bounded, browser-local Vibe library and preserves supported media when one reviewed article is deliberately shared. It does not publish a local magazine or resume an old Chat.

## What changed

- **Find Vibes** browses and searches retained article titles and text without a network request.
- The 160-card cache now protects room for up to 96 completed, non-questionnaire Chat-made Vibes so editorial refills cannot displace all reader-commissioned work.
- Durable DSH history can restore eligible completed answers after a relaunch without reopening or resuming their Chats.
- A Vibe article's supported music or video destination now survives private preview and optional public publication as a click-to-load player with an ordinary provider-link fallback.
- The sharing contract accepts only the original public URL for YouTube, Vimeo, Spotify, or SoundCloud. Supplied iframe sources, HTML, credentials, autoplay instructions, tracking, and unrelated hosts are discarded.
- Documentation now explains retention, search, recovery limits, and the public-media boundary.

## Upgrade and rollback

Finish active DSH work before upgrading. The friendly installer installs an immutable package and restarts only after idle confirmation.

To roll back, download the `0.15.2` release assets, install that versioned source, then restart DSH after current work finishes. Removing Vibeify does not delete DSH sessions, Codex authentication, DeepSeek credentials, or browser-stored Vibe preferences.

## Honest boundaries

The local library is deliberately bounded. An article already older than 30 days, previously evicted before this release, deleted from DSH history, or preserved only as a public share cannot be reconstructed automatically. Public media still depends on the provider allowing playback in the reader's region and browser; the original provider link remains available when embedding is unavailable.
