# Vibeify 0.16.0 — simple sharing and current models

This release brings manual link sharing and a less expensive default agent setup to the Mac experience.

- Share an existing public link directly. Copy it, select it when clipboard access is unavailable, or use the device's supported share action. You make the final social post.
- A private article still goes through its separate preview and explicit **Publish public link** action before its public URL can be shared.
- Social scheduling and automatic publishing are disabled. Existing queue data is retained but cannot resume publishing.
- GPT-6 Luna with Max reasoning is the default Codex lead. DeepSeek V4.1 Flash handles eligible bounded execution; Pro and stronger Codex specialists are used only when justified.
- The compatibility bundle pins DSH 0.1.5-rc.3 and Codex 0.157.0, with current DeepSeek routes and conservative peak-rate estimates.
- Previously separate questionnaire and nested Markdown-link fixes are included.

The friendly installers select this bundle's qualified DSH version. The update check can still report newer upstream versions without installing them automatically. Windows and Linux remain previews pending real-machine qualification.

An update preserves the private magazine and historical Social Desk data. Finish any active DSH task before activating an update.

## Operator verification

Before publishing this release, verify the source and package tests, generated client, full plugin and skill validators, package closure, clean installation, existing-profile migration, live Luna and delegated worker turns, and manual sharing. A successful model catalogue lookup or a passing unit test alone does not establish the user-facing flow.
