# DSH Vibeify 0.16.1 compatibility bundle

This source bundle aligns the governed bridge, provider-neutral experience, Visuals, and Social Desk with DSH `0.1.7-rc.2`. The governed bridge pins its Codex lead dependency to `0.157.1`; the separate upstream native `dsh-subagent-codex@0.1.7-rc.2` still declares Codex `0.153.4`. DSH peers use Cordis `4.0.4` and Schemastery `3.18.4`.

The installers qualify DSH `0.1.7-rc.2` and align exact legacy profile version pins in `package.json` and remove retired legacy package pins before adding immutable plugin snapshots. The alignment saves a local backup and leaves other pins unchanged. A running DSH task still requires an idle-confirmed activation after staging.

Verification: 239 governed tests, 19 Visuals tests, 11 Social Desk tests, 13 installer tests, checks, plugin/skill validation, installer source check, and governed/provider-neutral package dry-runs passed. An isolated DSH 0.1.7-rc.2 installation booted both ChatGPT-led and DeepSeek-only web profiles. An authenticated Codex 0.157.1 lead round trip returned the exact expected smoke-test answer. The existing macOS web profile upgraded in place and its restart check returned HTTP 200. Windows and Linux installers remain preview paths; they were not activated on those operating systems.

This release also includes playable content inside articles and shared pages, with shared-game engagement preserved. Sharing remains a user-controlled action.
