# DSH Vibeify 0.16.1 compatibility bundle

This source bundle aligns the governed bridge, provider-neutral experience, Visuals, and Social Desk with DSH `0.1.7-rc.2`. The governed bridge pins its Codex lead dependency to `0.157.1`; the separate upstream native `dsh-subagent-codex@0.1.7-rc.2` still declares Codex `0.153.4`. DSH peers use Cordis `4.0.4` and Schemastery `3.18.4`.

The installers qualify DSH `0.1.7-rc.2` and align exact legacy profile version pins in `package.json` before adding immutable plugin snapshots. The alignment saves a local backup and leaves other pins unchanged. A running DSH task still requires an idle-confirmed activation after staging.

Release status: source candidate. Source evidence: 239 governed tests, 19 Visuals tests, 11 Social Desk tests, 13 installer tests, checks, plugin/skill validation, installer source check, and governed/provider-neutral package dry-runs passed. Native runtime and activation evidence: pending isolated verification before publication.
