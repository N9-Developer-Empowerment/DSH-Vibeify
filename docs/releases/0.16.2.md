# Vibeify 0.16.2

Magazine palette, text size and spacing now apply and save immediately in Look & feel. The settings label updates with the saved palette. Chat colour remains independent; changing appearance does not generate articles or change model settings.

This patch also fixes the browser startup error `waiting for service: settingsScope` on DSH 0.1.7-rc.2 by using its current configForms service. DSH and Codex versions are unchanged from 0.16.1.

Validation: 239 plugin tests, generated-client and syntax checks. Final package, profile and live checks are recorded with the release.
