# Vibeify 0.16.3

Credited Wikimedia Commons images now take priority over fallback illustrations. This fixes captions whose creator or licence sits outside the Commons link, including the Robert Scott Burn steam-engine article verified in the local VIBE magazine.

Article cover selection now has one resolver and one caption parser. Rendering and sharing use the same selected image. Content-aware cache keys prevent old illustrations masking edited credits; transient lookup failures remain visible and retryable. Exact Commons requests never broaden into unrelated stock or generated artwork, and credited images are queued ahead of optional discovery.

The magazine obtains its DSH connection through the current service registry. README, visual guidance and the new article-image architecture document are updated.

Validation: 255 Vibeify tests, 21 image-service tests, 27 sharing tests and 13 shared-component tests; client build and syntax checks; plugin and skill validators; package dry-run; composed DSH profile check. Local activation succeeded and the user confirmed the credited Commons image renders correctly. DSH 0.1.7-rc.2 and Codex 0.157.1 remain the tested compatibility versions.
