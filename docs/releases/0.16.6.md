# Vibeify 0.16.6

Installed Vibeify now reports its package version instead of an outdated hardcoded bridge version. Windows update checks now read the running DSH installation instead of launching a Windows command wrapper. The Updates panel always offers the public update guide, including when checking fails. The website provides platform choices, checksum-checked copyable terminal commands, and explains unsigned-file approval without claiming Apple notarization.

The Windows installer asks for explicit confirmation before stopping an owned idle DSH process; it refuses unrelated listeners and rechecks process identity before making changes. The qualified DSH/Codex versions remain 0.2.0-rc.2 and 0.160.0. Visuals 0.1.1 and Social Desk 0.2.1 are included by the installers.
