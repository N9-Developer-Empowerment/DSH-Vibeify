# Vibeify 0.16.7

Keeps the original VIBE gossip magazine and BBC News mastheads for existing saved profiles and shared articles. Lilac Pop, Cherry Soda, Matcha Break and After Dark are explicit mood choices that combine with the website look and saved editorial direction. Each mood has its own palette, presentation, reusable masthead and writing voice.

Qualified runtime versions remain DSH 0.2.0-rc.2 and Codex 0.160.0. Windows automatic reopening remains a preview qualification issue; installation and update checks have been verified on MSI.
