# Vibeify 0.17.1 — magazine card and image recovery

Vibeify 0.17.1 fixes magazine-card ownership and improves image recovery while keeping the 0.17.0 provider setup: native DeepSeek V4.1 Flash 1017 (`deepseek-flash`) leads, with optional GPT-6.1 Sol support through ChatGPT-authenticated Codex. DSH `0.2.1-rc.2` and Codex `0.164.0` are unchanged.

## Changes

- DeepSeek reasoning output is no longer treated as magazine-card content. Final text and images reconcile only within the same owned chat, and distinct owner IDs prevent cross-chat overwrites.
- Placeholder-only cards and exact legacy duplicates are hidden; older cards with different content remain available.
- When a catalogue photograph fails to load, the card uses a labelled conceptual illustration. The illustration is not presented as a documentary image of the article subject.

## Evidence and limits

The implementation run passed 302 core tests. In a live BBC test, all three test articles (library, garden, and repair) loaded related photographs. A separate render contained 131 cards with covers, including 53 labelled illustrations. This does not semantically validate every older image. Image search remains best-effort and does not guarantee a matching photograph.

Release publication is gated by the pull request’s installer matrix, native runtime checks and downloadable-archive checks. See the repository Actions run linked from the release pull request. Windows and Linux remain preview platforms pending real-machine validation. These checks do not establish universal browser, device, or catalogue-image coverage.

## Compatibility

The DeepSeek lead model and optional worker remain unchanged from 0.17.0: DeepSeek V4.1 Flash 1017 leads; GPT-6.1 Sol remains the optional bounded Codex worker. DSH remains `0.2.1-rc.2`; Codex remains `0.164.0`.
